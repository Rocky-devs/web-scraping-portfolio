# Web Scraping Portfolio 🕷️

A collection of real-world data scraping and analysis projects built with Python.

## Projects

### 🗽 [NYC Business Scraper](./nyc-business-scrape)
Multi-industry business data pipeline using Google Maps Places API.
- 5 industries × 60 records = 300 businesses across Manhattan
- Interactive map visualization with Folium
- Tech: Python, Google Maps API, Pandas, Folium

### 🍽️ [NYC Restaurant Inspector](./nyc-restaurant-inspector)
Cross-source analysis combining NYC Open Data with Google Maps ratings.
- 10,000+ health inspection records via Socrata API
- Fuzzy matching across data sources
- Tech: Python, Socrata API, RapidFuzz, Pandas

### 📚 [Scrapy Book Scraper](./scrapy%20project)
Full-site scraper with automatic pagination and detail page extraction.
- Scrapes all 1,000 books across 50 pages
- Tech: Python, Scrapy

## Skills Demonstrated
- REST API integration (Google Maps, Socrata)
- Multi-page scraping with automatic pagination
- Data cleaning and deduplication
- Cross-source fuzzy matching
- Interactive map visualization
